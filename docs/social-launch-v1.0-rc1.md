# SolOS v1.0 RC1 Social Launch Pack

## LinkedIn

Hoje o SolOS atravessa uma fronteira importante: de conceito visual para uma camada operacional demonstrável.

O SolOS v1.0 RC1 organiza o produto em três partes honestas: Linux como base, um runtime intermediário em Rust e o SolOS como camada de operação. A atualização adiciona contratos tipados, manifesto de capacidades default-deny, aprovações visíveis, rastros persistidos do Ghost, uma semente determinística de avaliação, ação mediada, estado explícito de Wallet/Heart Pass, política de memória revogável e um gate de release repetível.

O ponto central não é prometer autonomia mágica. É tornar cada intenção inspecionável: o que foi pedido, qual rota foi escolhida, qual capacidade seria usada, por que existe aprovação, qual foi o resultado e como ele entrou no rastro.

Pulso e créditos continuam com fronteiras claras: consentimento, moderação, exportação, exclusão, limites e antifraude são requisitos — não rodapés.

Esta é a atualização em que o SolOS começa a se comportar como aquilo que sempre quisemos construir: uma camada operacional nativa para a era dos agentes, com agência humana no centro.
