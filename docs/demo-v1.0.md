# SolOS v1.0 Demo Script

Target duration: 4 minutes.

1. Open Home and state the three layers: Linux, runtime intermediary, SolOS operating layer.
2. Show live host facts from `runtime-core`.
3. Open Agent/Ghost and show request class, safety, tools, quota, approval reason, and route.
4. Show the persisted five-example evaluation seed and its pass rate.
5. Request Workspace launch. Pause at the visible approval.
6. Deny once to prove nothing executes; repeat and approve to show the mediated action completes.
7. Open Wallet. Explain Heart Pass verification, quota visibility, signed-session requirement, and BYOK fallback.
8. Open Apps. Show declared module capabilities and Pulso as a guarded preview.
9. Close with the honest boundary: SolOS v1.0 is a controlled, inspectable operating layer—not hidden autonomy.

Success means a reviewer can see intent, policy, approval, result, and trace without reading source code.
