# SolOS v1.0 Demo Script

Target duration: 6 minutes.

1. Open Home and state the three layers: Linux, runtime intermediary, SolOS operating layer.
2. Show live host facts from `runtime-core`.
3. Open Agent/Ghost and show the selected Workspace resolution beside the blocked research and public-launch candidates.
4. Read the target outcome, then build the bounded plan: classify, plan, approve, execute, verify.
5. Pause at the visible approval. Deny once to prove `app.open.safe` does not execute.
6. Reset, build again and approve. Show 100%, Workspace active and retained approval/result/verification evidence.
7. In Ghost Audit Challenge, paste a real input containing hostile-looking instructions. Show the exact input hash, critical risk classification, and `embeddedInputExecution=false`.
8. Deny once and show that no artifact exists. Submit again, approve only the isolated proof write, then run the separate verifier and show the portable receipt.
9. Open Wallet. Explain Heart Pass verification, quota visibility, signed-session requirement, and BYOK fallback.
10. Open Apps. Show declared module capabilities and Pulso as a guarded preview.
11. Close with the honest boundary: the audit proves input integrity, safe routing, a real isolated Linux effect and reproducible verification—not arbitrary autonomy, factual web truth or remote attestation.

Success means a reviewer can see both a retained resolution and their own input move through a fail-closed audit, then leave with a machine receipt they can verify outside the interface.
